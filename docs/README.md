# Documentation

This directory contains “physics-first” documentation for SFunctor’s anisotropic structure-function analysis.

- `docs/ANISOTROPIC_STRUCTURE_FUNCTIONS.md` – Definitions of structure functions, angles `(θ, φ)`, and the derived length scales `(ℓ∥, ℓ⊥, ξ, λ)`.
- `docs/MEASURING_ANISOTROPY.md` – How to measure anisotropy from structure functions (including the “equal-structure-function” mapping).
- `docs/THEORY_COMPARISONS.md` – What Goldreich–Sridhar and Boldyrev-type pictures predict, and what to compare in the data.
- `docs/HISTOGRAM_ANALYSIS_GUIDE.md` – How to compute moments/structure functions from the unified histogram output (`hist`, `delta_bin_edges`) and how to slice by `(θ, φ)`.
- `docs/WORKED_EXAMPLE_ANISOTROPY.md` – A step-by-step example (with Python snippets) that computes `S2`, builds `ℓ∥(ℓ⊥)` and `ξ(λ)` mappings, and fits scaling exponents.
- `docs/ADDING_YPM.md` – Notes for extending the pipeline to third-order mixed structure functions `Y^±` (work-in-progress).
